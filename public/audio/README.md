# Répertoire des Enregistrements Masters Audio

Déposez ici les fichiers audio réels d'Hervé Nanfang au format `.mp3`, `.wav` ou `.m4a`.

### Fichiers attendus :
- `pianobariste-live.mp3` : Extrait d'interprétation live au piano / piano-bar.
- `composition-theme.mp3` : Thème original instrumenté / orchestration.
- `mao-sound-design.mp3` : Démonstration de production, mixage ou spatialisation.
- `ia-musique-recherche.mp3` : Extrait sonore issu des recherches Musicien Augmenté™ & IA.

Dès qu'un fichier est déposé, renseignez son chemin dans `src/data/audio.ts` (ex. `src: '/audio/pianobariste-live.mp3'`, `status: 'ready'`) pour activer instantanément la lecture dans « La Scène Sonore ».
